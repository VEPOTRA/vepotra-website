# Vepotra Landing Page

A dark-first, developer-focused landing page for Vepotra, built with Next.js, React, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize first

- Replace the placeholder project cards in `app/page.tsx`.
- Change `hello@vepotra.com` to your real contact address.
- Replace the `#` social links with real profiles.
- Update the technology list to match your actual stack.
- Replace the temporary stats in the hero visual with real metrics when available.

## Production

```bash
npm run build
npm run start
```
